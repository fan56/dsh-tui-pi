# Startup plugin tree

Launching the TUI prints a startup tree of the whole plugin composition under the welcome banner — every profile plugin with its **installed npm version**, the bundled `dsh-base` count, and one glance-line for MCP servers, skills and plugin totals. Plugin versions come from the profile root, so what you see is what the process actually loaded.
